# Пакет start-frt

Пакет фронтенда стартовых страниц для Universo Platformo Ruby.

## Обзор

Этот пакет предоставляет стартовые страницы приложения Universo Platformo:
- Гостевая стартовая страница для неавторизованных пользователей (лендинг с секцией hero и карточками продуктов)
- Стартовая страница для авторизованных пользователей (мастер онбординга)

## Структура

```
base/
├── README.md           # Документация пакета (EN)
└── README-RU.md        # Документация пакета (RU)
```

Код реализации находится в корневом Rails-приложении:

| Путь в корневом `app/` | Описание |
|------|---------|
| `app/controllers/start_controller.rb` | StartController (редирект с корня + страницы) |
| `app/views/start/guest.html.erb` | ERB шаблон гостевой посадочной страницы |
| `app/views/start/authenticated.html.erb` | ERB шаблон мастера онбординга |

## Страницы

### Гостевая стартовая страница (`/start/guest`)
Отображается для неавторизованных пользователей. Показывает:
- Навигацию со ссылками входа/регистрации
- Секцию hero с заголовком и кнопкой призыва к действию
- 4 карточки продуктов (экосистема Universo)
- Подвал с контактной информацией

### Стартовая страница для авторизованных (`/start/authenticated`)
Отображается для авторизованных пользователей. Показывает:
- Навигацию с email пользователя и кнопкой выхода
- Многошаговый мастер онбординга (Приветствие → Интересы → Завершение)
- Подвал с контактной информацией

## Маршруты

```ruby
root "start#index"                          # Перенаправляет в зависимости от статуса аутентификации

get :guest, controller: :start, as: :start_guest
get :authenticated, controller: :start, as: :start_authenticated
```

## Зависимости

- Ruby on Rails 7.1+
- tailwindcss-rails для стилизации
- i18n с файлами локализации en/ru
